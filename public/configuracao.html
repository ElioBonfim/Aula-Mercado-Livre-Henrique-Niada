1Túnel e URLs para o aplicativo do Mercado Livre

O Mercado Livre só devolve o login e as notificações para um endereço HTTPS público. O painel abre esse endereço sozinho (um túnel) e ele aponta para este computador.

Passo a passo: criar o aplicativo no DevCenter
  1. Entre em developers.mercadolivre.com.br/devcenter com a sua conta e clique em Criar aplicação.
  2. Em URIs de redirect, cole a URI de redirect acima — exatamente como está, sem barra no final.
  3. Em URL de retornos de chamada de notificação, cole a URL de notificação acima.
  4. Em Fluxos OAuth, marque Authorization Code, Client Credentials e Refresh Token.
  5. Em Permissões, dê leitura e escrita pelo menos em Publicação e sincronização.
  6. Aceite os termos, resolva o reCAPTCHA e salve. Sem salvar, nada é gravado.
  7. Copie o App ID e a Chave secreta para o passo 2 abaixo.

A URL do túnel muda sempre que o painel é reiniciado. Quando mudar, este painel avisa no topo de todas as telas; é só voltar ao DevCenter e trocar as duas URLs.

    Claude Code (perguntar em vez de procurar)

    O projeto já vem com uma ponte para o Claude Code. Com ela você pergunta por escrito e ele responde com os seus dados — os mesmos deste painel: anúncios, melhores produtos, curva ABC, visitas, vendas, lucro. Não precisa instalar nada nem entrar de novo: ele usa a conta que você conectou aqui.

    Pasta do projeto

    A linha entra na pasta do projeto e abre o Claude Code ali. É por estar nesta pasta que ele enxerga os seus anúncios.

    Passo a passo: ligar o Claude Code aos seus dados
    1. Conecte a sua conta do Mercado Livre no passo 3 acima. Sem conta conectada não há o que consultar.
    2. Abra o Terminal e cole a linha acima.
    3. Na primeira vez ele pergunta se pode usar o servidor mercado-livre deste projeto. Responda que sim.
    4. Para conferir, digite /mcp: mercado-livre tem de aparecer como connected.
    5. Pronto — é só perguntar em português.

    Exemplos: “quais foram meus 10 melhores produtos nos últimos 30 dias?” · “quem está na curva A?” · “o MLB123… está perdendo visitas?” · “grave custo de R$ 42,30 no MLB123… e me diga a margem” · “o que o Mercado Livre sugere melhorar nos meus anúncios?”

    A conversa acontece só neste computador: o endereço público do túnel não publica nada disso. Para deixar a ponte apenas consultando, sem poder publicar nem editar, escreva ML_MCP_ESCRITA=0 no arquivo .env e reinicie.
